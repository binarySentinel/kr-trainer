# Подготовка к контрольным

Тренировочные варианты контрольных работ для 1 курса ФПИиКТ:

- **Программирование, контрольная работа №1** — 20 вопросов, 30 минут (вывод Java-программ, тесты, верно/неверно).
- **Программирование, контрольная работа №2** — 20 вопросов, 30 минут: ООП (SOLID, переопределение и перегрузка, полиморфизм, инициализация, исключения, enum, record, интерфейсы).
- **ОПД, рубежный контроль №1** — дерево каталогов, содержимое файлов и права доступа в терминале; сложение в 16-разрядном дополнительном коде и флаги C, V. 60 минут.
- **ОПД, рубежный контроль №2** — таблица трассировки программы БЭВМ (IP, CR, AR, DR, SP, BR, AC, NZVC) и формула, которую вычисляет программа. 60 минут, есть режим обучения.

Сайт: https://binarysentinel.github.io/kr-trainer/

Варианты 1–20 фиксированные, «случайный вариант» каждый раз новый. Ответы и история попыток хранятся только в браузере пользователя.

## Структура

- `index.html` — готовый сайт (собран из `src/`).
- `src/gen.js` — генераторы вариантов, `src/shell.js` — терминал, `src/kr2.js`, `src/kr2code.js` — вопросы КР №2 по программированию, `src/bcomp.js` — модель БЭВМ-NG (сверена с эмулятором bcomp-ng 2.45), `src/app.js` — интерфейс, `src/index.html` — шаблон и стили.
- `tools/build.py` — сборка: `python3 tools/build.py` записывает `index.html`.

Настройки (время, ссылка на донат) — блок `CFG` в начале `src/app.js`.
